# Grub2 Theme CachyOS
##### All Credits goes to : diegons490
##### This is a forked Version of the CachyOS-Grub-Theme with a bit more minimalism and changed Background Image.

#### Installation Guide :
- Copy this Github Repository by this Command 
```bash
git clone
```
- Open the Folder Path in Terminal 
```bash
cd ~/cachyos
```
- Now run 
```bash
sudo bash setup.sh
```
- The Simple Installation Menu will appear.
